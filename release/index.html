日记

装在自己的手机上。文字和照片留在这台设备里，不经过应用商店。

当前安装包 1.0.0

第一版：写日记、配图、按日摘要，以及从这里安装。

下载 APK

文件名 diary.apk。建议用手机浏览器打开这一页再下载。

在 vivo 上安装

vivo S30 Pro Mini 一类机型使用 OriginOS。系统会拦住「未知来源」的安装包，按下面做即可。菜单名字在不同版本里可能差一两个字。

  1. 用手机浏览器打开这个页面，点「下载 APK」。
  2. 下完后，从浏览器的下载列表或「文件管理」里点开 diary.apk。
  3. 如果提示风险，选择「继续安装」或「仍要安装」。
  4. 如果按钮是灰的，或提示禁止安装：打开「设置 → 安全」或「安全与隐私 → 更多安全设置」，进入「安装未知应用」（有的版本叫「外部来源应用」），允许刚才使用的浏览器或文件管理。
  5. 若开了「纯净模式」或 i 管家拦截，对这一次安装选择允许。纯净模式一般在「设置 → 安全 → 纯净模式」。
  6. 安装时看清应用名称是「日记」。装好后到「设置」里填写 DeepSeek API Key，摘要才会工作。不填也能写日记。

装好之后如何更新

应用启动时会读取你在「设置」里填写的 version.json。如果里面的 versionCode 比手机上的大，会询问是否下载并交给系统安装器。请允许「日记」安装未知应用，否则下完也无法安装。

当前 version.json 的 apkUrl 仍是示例地址。手机上的「检查更新」会去下载那个地址。把 apkUrl 改成这个 diary.apk 的真实网址后，应用内更新才会下到正确的包。这一页的下载按钮始终指向旁边的 diary.apk。

托管这个文件夹的人

把整个 release 目录放到任意静态网站或局域网 HTTP 服务上。本页、version.json、diary.apk 需要能通过同一个站点访问。

然后编辑 version.json，至少改这两处：

  1. apkUrl：diary.apk 的完整地址，例如 https://你的域名/diary/diary.apk。
  2. 发新版时同时提高 versionCode，并让 APK 里的 versionCode 与它一致。versionCode 只能变大，签名必须仍是同一把密钥。

示例：cd release && python3 -m http.server 8080。手机和电脑在同一网络时，把更新地址设为 http://电脑IP:8080/version.json。
